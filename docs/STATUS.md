## Решения (журнал)
- 2026-10-29 · WS-14 (OOM): **ComfyUI не дедуплицирует загрузчики моделей** — каждый узел `CLIPLoader` с одним и тем же файлом создаёт свой объект CLIP (~25 ГБ на Qwen3-VL int8). Причина всех трёх OOM: не H3, а дубли загрузчиков (собраны из нескольких движков) + RAM-кэш ComfyUI. Решение: склейка одинаковых загрузчиков (`tools/dedup_loaders.py`), намеренно раздельные (проход лица) защищены. Профиль фермы → `frame_ls@2` (−25 ГБ в производственном пути). Под при лимите < 200 ГБ: `--cache-none` (не `--cache-lru 10`) — LRU-кэш тоже держит энкодер 25 ГБ. Студия сейчас с `--cache-ram 8 24` → перезапуск с `--cache-none` (действие пользователя). Проверка памяти — только по cgroup (`/sys/fs/cgroup/memory.current`), `/system_stats` на поде показывает ОЗУ хоста и врёт.
- 2026-10-29 · WS-12/WS-13: адрес пода в `tools/vsr_run.py` вынесен в переменные окружения (`POD_SSH_HOST`/`POD_SSH_PORT`/`POD_SSH_KEY`/`POD_SSH_USER`) — репозиторий публичный, IP пода в коде не хранится.
