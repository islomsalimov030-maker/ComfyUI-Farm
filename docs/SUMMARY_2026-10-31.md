## 2. Архитектура фермы (как есть)

**Таблица сцен** (xlsx / Google Sheet, схема `farm/sheet_schema.yaml` v2.1, CONTRACTS v0.9–0.10): строка = шот; персонаж =
персонаж + наряд; зона → location sheet (`refs/zones/<зона>/sheet.*`); колонки позы/действия по-русски, длительность, петля,
видео-реф движения, фото-реф позы; секси-вариант — отдельный шот `-X` (наполняет команда).

**LLM промптов**: `farm/prompts` — LLM (Ollama `qwen3-vl:8b-instruct`, JSON-схема, temperature 0) пишет только поля, строку
собирает шаблон; длина по сетке 17k+5; линтер h3-prompt-writer → до 2 ремонтов, иначе `needs_human`. Варианты бэкенда в ноде
«Таблица → промпты»: transformers (GPU), llama.cpp, Ollama.

**RefMod-моды** (ComfyUI-MiniMaxH3Mod, MIT; Picker, MIT): `farm/<персонаж>_face`, `farm/<вариант>_body` (персонаж в наряде);
кадр без LoRA и без листа персонажа — только моды + location sheet; проход лица — мод лица, денойз 0.85, 1 Мп.

**AIO_auto** (бывш. `farm_auto@1`): ТАБЛИЦА (`NGFarmShotFromTable`, row + increment, Queue ×N) → ЛОКАЦИИ (по имени зоны) →
ФОТО (сабграф «ДВИЖОК ФОТО»: H3 ref-edit, 3 Мп, проход лица; модели включателями ПУЛЬТА ФОТО — ref2v / Singularity /
10Eros / PinkCherry, по очереди) → ZIP фото → ВИДЕО (сабграф «ДВИЖОК ВИДЕО»: ref2va, 1344×768 → петля
`StacyLoopSeam/Extend/Fold`, цвет, анти-дрожь, проход лица fl2va + turbo, RTX VSR → FullHD 24 fps) → ZIP видео.

**AIO_manual** (бывш. `farm_manual@1`): те же движки с ручными входами (маска, кадр), + сабграф «ПРОХОД ЛИЦА готового видео».

**Оркестратор** (`farm/worker.py` + API-движки `frame_ls@2`, `video_h3_loop@1/2`): очередь в SQLite, ретраи ≤3, QA кадра
и видео, бот-ревью. Код готов, на поде целиком не прогонялся.

**Проход лица**: кадр — H3 + мод лица; видео — fl2va + turbo 4 шага (+ LoRA Стейси 0.75 только в `stacy_facepass`), трекинг
кропа, flow-lock, вклейка. **Петли**: StacyLoop (MIT) — seam/extend/fold, авто-кроссфейд; после FlashVSR — финальный seam.
**ZIP**: `NGFarmZip` → ссылка на скачивание; `NGFarmFrameFromFolder` берёт кадры из папки/ZIP для видео.

## 3. Действующие решения (сводка журнала STATUS)
- Только локальные модели; ферма нейтральна к содержанию, ассистент пишет и тестирует только SFW.
- Оркестратор — пакет нод ComfyUI-Farm, состояние в SQLite `/workspace/farm`; узлы по `title`; пороги в YAML; контракты через CONTRACTS.
- LLM/VLM — Ollama; LLM пишет поля, строку собирает шаблон; линтер обязателен.
- Кадр: без LoRA и листа персонажа — RefMod + location sheet зоны, 3 Мп; наряд не указан → базовый (серый топ + белые шорты).
- Масштаб: исправление размера после генерации исключено; силуэт нужного роста — рабочий 2D-рычаг для стоя.
- Видео: ref2va + turbo 8 по умолчанию; Singularity / 10Eros / PinkCherry — 20 шагов без turbo; beta4 исключена (только beta5).
- Прод без InsightFace (buffalo_l, SCRFD) и Depth Anything V2 Base/Large; лицо — MediaPipe + AuraFace (Apache-2.0).
- Смысловые проверки видео (вода/пар, «не то движение») и руки — человек в боте.
- RES4LYF и DaSiWa не используем; SMPL/SMPL-X/OpenPose CMU (NC) — не используем.
- Стейси: 22 года, рост 162 см (решение 13.10, записано в лист «Персонажи»).
