1. PyYAML для Blender (разрешено пользователем).

   Проверка: blender -b --python-expr "import yaml; print(yaml.__version__)".
   Системный Python и Python Blender не трогать.

2. Зоны прокси (решение принято).
   Набор зон = ключи outfit_colors из characters/<id>/body.json, число не фиксировано.
   Вершины без зоны красятся цветом outfit_colors["skin"]. Если ключа skin нет, использовать #C8A08A.
   Тест переписать: (а) 100 % вершин окрашены; (б) набор зон в раскраске == набору ключей body.json (плюс fallback); (в) проверки «ровно 6 зон» нет.

3. Единая метрика проникновения.
   place() и валидатор должны вызывать одну функцию: p95 проникновения по каждой поверхности, soft 6 см, hard 3 см (из config/placement.yaml).
   Если сейчас где-то используется max или другой перцентиль, заменить вызовом общей функции.
   Добавь тест: одинаковый вход даёт одинаковое число в place() и в валидаторе.

4. Высота: контакт и потолок (Q04).
   В place() после выбора зоны:
   (а) опускать или поднимать тело по вертикали, пока min расстояния вершин support_parts до target_object не станет 0 ± contact_tol (contact_tol взять из placement.yaml; если ключа нет, добавить contact_tol: 0.01 м);
   (б) затем проверить p95-проникновение (п.3); если превышен лимит, поднимать шагом 0.5 см до выполнения лимита, но не дальше contact_tol + 1 см от контакта;
   (в) если (а) и (б) несовместимы, статус partial, флаг height_conflict.
   Порядок (а)→(б) обязателен.

5. Крен и спинка (T03).
   (а) Кламп крена ±15° применять при сборке ориентации, до зоны и высоты. Найди и убери любой путь, где крен ставится после клампа (refine включительно: refine не меняет крен за пределы ±15°).
   (б) recline: после высоты вращать корпус вокруг таза в пределах наклона класса из placement.yaml, пока спина (вершины зоны torso_back) не коснётся спинки в пределах contact_tol с hard ≤ 3 см. Если в диапазоне не достижимо, статус partial, флаг no_back_contact.
