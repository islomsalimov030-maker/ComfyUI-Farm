1. ОРИЕНТАЦИЯ LIE (решение координатора)
Кламп крена ±15° применять только к stand, kneel, sit_edge, sit_tucked, sit_floor, crouch, all_fours, recline. Для lie:
- поворот вокруг вертикали — с рефа, с сохранением стороны тела к камере (как сейчас);
- длинная ось тела (таз → шея) ставится параллельно плоскости верха поверхности; допуск наклона оси к плоскости ≤ 15°;
- крен вокруг длинной оси берётся с рефа без клампа (на боку ≈ ±90°, на спине ≈ 0°, на животе ≈ 180°).
Флаг orient_clamped для lie больше не выставлять.
Тесты: синтетическое тело на боку сохраняет крен ±90° ±10° после place(); тело на спине — ±10°.
Перепрогон Q04. Плейбласт должен глазами совпадать с рефом: на боку, голова на руке.
