Роль: исполнитель, строго по пунктам, архитектурных решений не принимаешь. Если пункт невыполним — пропусти ТОЛЬКО его, запиши причину, остальное доделай. Скил stacy-farm-ops. Только SFW. На сервере студии ничего не ставить, не перезапускать, Manager не трогать.

ЦЕЛЬ: подготовить пак ComfyUI-3DA к установке на сервер студии одним скриптом админа. Сервер: Linux, ComfyUI 0.34.6, Python 3.13, torch 2.13+cu130, флаги --lowvram --cache-none, общий; в ядре уже есть SAM3DBody_*, MoGe*, Load3DAdvanced, нативный H3.

ПЕРВЫМ ДЕЛОМ: сохрани промпт в docs/coord/3DA_SERVER_PORT_<дата>.md, коммит.

ПУНКТЫ
1. Конфиг пака config/3da_server.yaml (+ переменная окружения THREEDA_DATA_ROOT): data_root, blender_path, cache_dir. Все пути в нодах и воркфлоу — относительно data_root. Ни одного C:\ и ни одного ../ в коде и воркфлоу. Значение по умолчанию на сервере: <ComfyUI>/user/default/3da_data.
2. Загрузка данных без терминала: скрипт scripts/push_data.py (запускается на ПК) — заливает profile.json, body.json, меши, ассеты предметов в data_root через POST /api/userdata/<путь> на сервер; повторный запуск идемпотентен. Проверь на 1 локации (mainroom3) и 1 персонаже (stacy) — только на ПК-копии ComfyUI 0.34.6 или моке, НЕ на сервере.
3. Серверный воркфлоу 3DA_scene_server_v1.json: вместо 3DAH3Remote — сабграф «Движок H3 (не трогать)» из 3DA_h3_server_v1.json прямо в графе (Remote на сервере даст взаимную блокировку очереди). ПК-версия воркфлоу остаётся с Remote.
4. requirements.txt: без torch, torchvision, numpy-переустановок; версии совместимы с Python 3.13. Если SAM 3D Body / MoGe можно вызвать через ноды ядра — используй их на сервере вместо своего venv; если нельзя — запиши почему.
5. scripts/install_server.sh (для админа, идемпотентный, без sudo внутри ComfyUI): git clone/pull пака в custom_nodes; скачать Blender <та же версия, что на ПК> Linux tarball в /opt/blender-<версия> (только если нет); pip install -r requirements.txt в окружение ComfyUI с --no-deps для пакетов, которые тянут torch; создать data_root; вывести итог. Отдельно scripts/update_server.sh (git pull пака + список, что нужен перезапуск).
6. Исправь кодировку: все строки title и Note во всех воркфлоу, испорченные двойной перекодировкой (s.encode('cp1251').decode('utf-8')), — исправить; добавить тест, что в JSON нет последовательностей «Р[А-Яа-я]Р» массово.
7. Лицензии всех новых зависимостей и Blender — в docs/RESEARCH.md.

КРИТЕРИИ: на чистой ПК-копии ComfyUI (Python 3.13, без пака) install_server.sh ставит пак, ComfyUI стартует, ноды 3DA регистрируются, 3DA_scene_server_v1 проходит постановку Q04 без H3; pip freeze до/после — torch не изменился; в воркфлоу нет C:\ и ../; тесты OK.
