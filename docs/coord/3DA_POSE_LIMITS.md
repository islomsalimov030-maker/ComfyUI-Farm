# 3D-A · кости и пределы суставов нейтрального манекена (07.11c)

Манекен: `C:/work/scene3d_work/stacy_neutral_162.blend` (риг MPFB, 163 кости, L/R-симметрия длин — да).
Код: `tools/scene3d/pose_tools.py` — углы меряются **геометрически** по головам костей в пространстве арматуры
(не зависят от способа постановки: повороты, `@reach`, LLM, ретаргет). Проверка встроена в `render_plate_scene.py`:
после позы → `measure` → предупреждение `[limits] WARNING …` → `clamp` (кости сустава slerp к покою, бинарный поиск,
пока угол не войдёт в диапазон; `"no_clamp": true` в сцене — только отчёт). Итог в `<scene>/pose_metrics.json`.
