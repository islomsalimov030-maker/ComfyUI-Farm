**3. Почему генерация долгая (по нашим замерам)**
1. Попадание в позу и место — перебором сидов: без 3D-манекена человек встаёт не туда и не в том масштабе.
2. Комната перерисовывается в каждой попытке и «плывёт» — кадр бракуется по фону, а не по человеку.
3. Проход лица на мелком лице (< 60 px) с сильным денойзом меняет поворот головы и одежду — ещё одна попытка.
4. Сложные позы (лёжа, профиль, взгляд вниз) не проверяются автоматически — уходит ручной просмотр.

**4. Что предлагаем**
1. Для фото-строк — 3D-путь V2.3: поза/место по манекену, комната = исходное фото, тень от фигуры.
2. Проход лица: 0.35 по умолчанию; 0.85 — только если лицо крупное, анфас и сходство < 0.6.
3. Сложные позы ставить по референсу или по картинке (раунд поз), а не текстом; лёжа — средним планом.
4. Вести журнал попыток (строка, сид, секунды, вердикт) — он уже собирается автоматически в 3D-пути.
