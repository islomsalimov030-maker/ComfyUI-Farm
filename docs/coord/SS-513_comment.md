## Где теряется время

1. Повторные попытки из-за несовпадения позы, места, масштаба и наряда. Число попыток до приёмки нужно записывать, а не только секунды одного sampler.
2. Подбор контакта с мебелью: сиденье/стопы/руки нужно проверять на дешёвом плейбласте до GPU-генерации.
3. Загрузка/смена ref2va,FL2VA,SAM3,Qwen. Группировать кандидатов по одной модели, затем лица; не чередовать модели на каждом шоте.
4. Гармонизация и FacePass каждого кандидата до отбора. Сейчас гармонизацию не делать обязательной; лицо запускать на отобранных кадрах.
5. Ручной экспорт, поиск файлов и повторный сбор таблицы. Нужны shot_id,seed,recipe,тайминги,вердикт и причина брака в durable manifest/ZIP.

## Конкретные оптимизации и ограничения

- 3D-плейбласт как Video1 помогает попадать в позу/место: в текущей серии8/8, но обещать попадание с первой попытки для любой сцены пока нельзя.
- Для проверенного рецепта base без turbo предпочтительнее прежнего turbo по визуальному качеству, не по скорости одного шага. Сравнивать секунды на **принятый** кадр.
- Автоотбраковка PCK/человек/лицо внутри графа — следующий этап; сейчас QA внешняя. DWPose/VGGFace2 диагностические, для прода лицензии/калибровку закрыть, лицо заменить/сверить с AuraFace.
- FacePass только если sim<.6 и лицо надёжно обнаружено; отсутствующее/закрытое лицо не равно sim0, такие кадры направлять на визуальное решение. Порог.6 относится к текущему измерителю, между моделями лиц не переносится автоматически.
- Гармонизация только по необходимости: .30/.45 в серии не доказала выигрыш. Тени из Cycles H3 переносит недостаточно, PERSON-композит может удалить тень за пределами тела — вписанность пока открыта.
