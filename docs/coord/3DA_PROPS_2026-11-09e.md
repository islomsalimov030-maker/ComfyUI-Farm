1. РУЧНОЙ ТРАНСФОРМ ТЕЛА (в Place Pose)
- Поля body_dx, body_dy, body_dz (м, оси локации: x вправо по кадру, y вглубь, z вверх), body_dyaw, body_dpitch, body_droll (°, вокруг центра таза). Масштаб задаётся через height_m.
- Применяются после place(), затем валидатор пересчитывает статус и флаги (не блокируют, см. 0a).
- Кэш постановки по хешу входов тела: изменение только body_* или предмета не перезапускает SAM 3D Body и place() — только трансформ, валидация и рендер.

2. БИБЛИОТЕКА ПРЕДМЕТОВ
- props/<id>/: модель (.glb/.gltf/.fbx/.obj) и prop.json со полями name, size_m (длинная сторона, по умолчанию из модели), description_en (пусто — заполнит пользователь), prop_strength (0.35).
- Импорт через Blender: единицы → метры, origin в центр bbox, материалы и текстуры сохраняются, нормализованная модель кэшируется.
- Скрипт import_props проходит props_source_dir и создаёт props/<id>/ с черновым prop.json.

3. НОДА «3DA Prop»
- in: props_in (optional, для цепочки), prop_id (список из props/), anchor (world | char_head | char_chest | char_hand_l | char_hand_r | char_pelvis), x, y, z (м, смещение от якоря; для world — от центра таза тела), yaw, pitch, roll (°), scale (множитель к size_m), prop_strength (FLOAT, по умолчанию из prop.json).
- out: props (STRING, json-список).
- Предмет висит: опоры и контактов нет. Флаги prop_hits_room, prop_hits_body, prop_out_of_frame выводятся, но не блокируют.

4. ИНТЕГРАЦИЯ В Place Pose (вход props, optional)
