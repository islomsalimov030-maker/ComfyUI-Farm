# 3D-A · решения мозга по 07.11c → заход 07.11d (Claude Code только исполняет)

## Решения
1. **B (Z-Image → SAM 3D Body → ретаргет) — основной способ постановки позы.** C — тот же конвейер, когда есть референс
   пользователя (`C:\Users\user\Downloads\3DA_pose_refs\<Qxx>.jpg`). A (qwen3:8b) снят, код остаётся.
   SAM 3D Body на сервере 0.34.6 нет → B остаётся шагом на ПК (плейбласт + shadow), дальше AIO V2.3 на сервере.
2. **Решатель контактов с приоритетом опоры** (мозг, `pose_tools.solve_contacts`, уже в репо): опора = сильнейший класс
   (таз/спина > бёдра/колени/голени > стопы > локти > кисти), садится точно (самая глубокая точка опоры = 0, без
   усреднения с остальными); вторичные кисти/стопы доводятся IK конечности (`reach` для руки, новый `leg_reach`),
   потом clamp и повторная посадка; колени/локти/бёдра вне опоры — только отчёт. `"role": "support|secondary"` в
   контакте переопределяет. Метрики пишут `support` и `limb_fix`.
3. **V2.3 → `aio-v23-ui-3-server`** (мозг, уже в репо): генерация 1344×768, но вклейка и выход — в размере V2.2
   (фото → мегапиксели V2.2, кадр апскейлится до того же размера, SAM3 на большом кадре, перо 6/9, тень тоже).
   В `aio_v23_object_info.json` для `GetImageSize` и `ImageScaleToTotalPixels` — заглушки мозга (`_stub`), заменить схемами сервера.
4. **Планы без смены камеры** (мозг, `plan_crop.py`, `pose_h3.py --plan full|medium`): фото, плейбласт, тень, маска
   режутся одним прямоугольником с аспектом фото; зум ≤ 2.5×. Лёжа и на коленях — проверяем этим.
