## Решения по открытым вопросам
1. **LIE01 (лёжа)** — не отдельный рецепт. Причины: поза `lie_back` неестественна (перекрученный корпус, руки на груди),
   фигура мелкая (184 px голова–стопы). Лёжа переходит в раунд поз (docs/coord/3DA_ROUND_POSES_2026-11-07.md): поза из
   способов A/B/C на нейтральном манекене + план «средний» (кроп с той же точки), чтобы фигура была ≥ 400 px.
2. **Профиль / лицо вниз** — да, приёмка глазами. Правило измерителя: сходство считается, только если лицо ≥ 60 px и
   видны оба глаза (DWPose face points); иначе вердикт «visual». Для таких кадров проход лица только 0.35 (0.85
   доворачивает голову и тянет одежду из мода — жёлтый воротник STD01).
3. **AIO V2.3 на сервере** — сделать серверный вариант **без Fun CN вообще**: победитель S3 comp2 его не использует.
   3D-ветка = плейбласт `<Video 1>` + SAM3 person + вклейка в фото с тенью **внутри графа** (core: ImageCompositeMasked,
   умножение фото на (1 − 0.8·shadow) — ImageBlend multiply или аналог из уже стоящих паков; без ПК-скриптов), затем
   штатный проход лица. Файл `AIO_manual_V2.3.ui.json` (сервер); вариант с Fun CN — позже отдельным `V2.3-pod`.
   Проверка: экспорт фронтендом сервера, 3D OFF = V2.2, 3D ON — один SFW-прогон (STD01) на сервере.
4. **SS-513 — не публиковать.** Задача просит пройти ТЕКУЩИЙ процесс (как у Нины) на 5 фото таблицы Стейси. Нужен базовый
   замер: 5 строк реальной таблицы через AIO V2.2 — делает пользователь сам (NSFW-строки мы не гоняем), время каждой
   и число попыток. Потом комментарий: короткий, для PM — (1) что сделано, (2) время по старому процессу vs новый
   3D-путь, (3) 3–5 причин, (4) 3–5 действий. Технику — ссылкой на отчёт. Черновик переписать в этом формате с
   плейсхолдерами под базовые цифры пользователя.
