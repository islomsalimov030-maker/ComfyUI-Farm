# 3D-A10a: исправление пользовательского Fit/camera

После пользовательского запуска получен чёрный крупный план. Фактические local prompt_id: e3862b29-8c04-4ef4-9484-a3b34d03d47f,92984c98-2976-4c5c-8deb-4b9ba657feda,0e5a48fe-7248-416d-beee-c241f076e9aa. Это три пользовательских H3-задания после бюджета ревизии09h, не дополнительные запуски агента.

## Причина

Во входах Load3DAdvanced появился scale16.66666766, центр(0,2.5,0) Three и другая камера: характерное штатное преобразование Fit. Исходный GLB уже .30м, поэтому итоговый размер стал2.9342×3.8354×5м. Предмет оказался у камеры основного рендера; frame_inside_fraction=0, но body-status осталсяok. Локальная prop alpha/guard заняла весь raster. Raw H3 последнего задания bf264f02-4b46-4111-9665-abab9ed2a7a4 содержит нормальную комнату и персонажа. Чёрный кадр создаётся локальным гигантским предметом; это не провал модели H3.

Недочёт09h: предупреждения/инструкции «не нажимать Fit» было недостаточно; prop flags не участвовали в итоговом status и допуске H3. Исправлено в коде, CONTRACTS v0.21, пак0.2.1.

## Исправление и доказательства

- Prop сверяет camera_info с plate.json через Location, с порогами в YAML. Fit/orbit/pan/FOV/zoom не принимаются молча. Native core UI не модифицирован; готовая Load3DAdvanced сохранена.
- Итоговый status включает prop frame/collision, body_status/body_validation сохраняются отдельно. body_guides.validation блокирует H3 до транспорта даже при непустом промпте и manual block_on_fail=False. Новый GeometryRejected виден в Comfy как ошибка, вместо сохранения фиктивного final.
- Safe-пресет восстановлен: реальный UI→8187 prompt5a9f90c2-d933-4edb-b2d0-4b2ea4239cf4, statusok, размер.1760535×.2301245×.29999995м, prop frame_inside1.0, пересечений нет; Remote muted и отсутствует в API.
- Реальные ошибочные camera/transform повторены локальным preview без Remote:870743d3-481d-4f59-ac7e-53926c919754. Ожидаемый execution_error на Prop за.17с. Отправки студии нет. Сохранённый реальный плохой report теперь даёт out_of_frame; отдельный H3 preflight отклоняет его до транспорта.

- Исправленная локальная вклейка проверена на уже завершённом пользовательском H3: outside0px, SSIM.9999945903. Плита и strength совпали байтово; новый init отличается максимум2 уровнями/1217px, playblast9/1864px после повторного рендера.
