## 1. Что такое RefMod (факты из кода)
Пакеты: [ComfyUI-MiniMaxH3Mod](https://github.com/Luisacaotica/ComfyUI-MiniMaxH3Mod) (MIT, у нас `f946208` = HEAD `517e8c4` по коду)
и форк [ComfyUI-H3RefModPicker](https://github.com/FranckyB/ComfyUI-H3RefModPicker) (MIT, `c732f8b`). Оба стоят на comfy.next-genium.com; своих модов там нет (только пример автора — персонаж Disney, не брать).

- Мод = **сохранённые латенты H3 video VAE** референсов (`[1,24,T,H,W]` + JSON-метаданные), без обучения весов H3.
  `Full Reference` (`encode`) — латент как есть; `Compressed Reference` (`training`) — пул в сетку `pool_h×pool_w` + MSE-дотяжка.
- Применение (`MiniMaxH3RefModApply`) дописывает латенты в `minimax_refs` условия — как ещё один референс рядом с `<Picture N>`; промпт мод не видит, триггер-слова нет.
- **Несколько картинок в моде — стопка по времени, не усреднение.** Холст задаёт первая картинка, остальные кропаются по центру под её пропорции → все кадры мода одного аспекта.
- **Бюджет токенов**: `T × (H/32) × (W/32)` для картинки; 1024×1024 → 1024 токена, 16:9 с короткой стороной 1024 → ~1824. Дефолт `max_tokens` 5120 (H3Mod) / 8192 (Picker), переполнение по умолчанию **молча обрезается** (`budget_policy=truncate`). Каждый токен — цена на каждом шаге DiT.
- **Маска** (`mask` / `mask_list`, у Picker — альфа PNG) не вырезает фон: вне маски латент смешивается с размытой копией (`background_retention`, 0 = только размытие). «Только кисть из большого кадра» маской не получить — зону надо **кропать** отдельным кадром, маской гасить остаток.
- Сила: `strength` (слот) × `retention` (Apply) — это смесь латента с его размытием, не вес внимания. Уровни автора: 1.0 / 0.7 / 0.4 (атрибуты без личности) / 0.15. `copies` 1–10, автор: 2–3 — «sweet spot».
- Автор рекомендует **5–10 разных чётких кадров**; выигрыш 15–20 не измерен. Предупреждает: личность, одежда, фон и композиция могут смешиваться.
- Совместимость с дообученными H3 (Singularity, 10Eros) не заявлена — проверяем сами.
- Для фермы: создание — `H3RefModCreateFromFolder` (Picker; `use_subfolders` = мод на подпапку) или `MiniMaxH3RefModExtract`; применение — `MiniMaxH3RefModsLoader` + `MiniMaxH3RefModApply` (H3Mod, уже в `tools/ws07_graphs.py`, генератор `A_refmod`). EXIF-поворот Picker не учитывает (issue #2) — кадры поворачивать физически.

## 4. Референсы или LoRA
RefMod не обучается: дёшево собрать/заменить, но платим токенами на каждом шаге и рискуем протеканием композиции. LoRA — один раз обучить, бесплатно в инференсе, требует 20+ чистых кадров. Критерий для AC-4: если мод 5–10 кадров даёт прирост против LoRA-only без утечки фона — категория идёт в RefMod; если прирост растёт до 20 кадров и упирается в бюджет токенов — кандидат на LoRA (SS-335).
