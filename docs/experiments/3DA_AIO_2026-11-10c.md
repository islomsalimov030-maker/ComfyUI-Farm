# 3DA/AIO 10.11c — реализация и фактические проверки

**Статус: частично принято, полный studio E2E не выполнен.** Код пакета0.3.0, новые UI/API, builder и manifest подготовлены локально в scene3d-pilot. Backend camera/frame guards сохранены. Источник — пользовательский AIO V2.0 с SHA256 `5b6e88d9f743e516d9f059e50081513c788a9bfd1a57f21aa22f8e775e7cd1b6`; оригинал не изменён.

## Реализовано

- Camera lock действует на реальную core viewport camera, включая повторное включение OrbitControls после drag-release; Fit заблокирован до изменения модели. Camera-only restore сохраняет transform. Холст ComfyUI остаётся отдельным.
- Общий GLB содержит настоящий cached SAM body и отдельные props. Встроенный selector и меню выбирают объект; core TransformControls меняет только выбранный root. Именованные transforms всех объектов сериализуются, отдельный checksum/placement key/camera guard не позволяет применить чужую сцену. Body translation/rotation проходят полный mesh/KP revalidation; размеры не масштабируются гизмо.
- В AIO сохранены все41 исходных верхних узла и4 исходных сабграфа; добавлен engine источников позы. Видео и ready-video face-pass не переписаны. Оба существующих RefMods Loader сохранены, новый NativeApply берёт исходный mods input и исходные retention/curve/token settings. Native H3 работает в этом же графе, Remote отсутствует. Итоговая композиция идёт после photo face-pass.
- Pose source: upload, Z-Image Turbo T2I, Qwen Image Edit2511 с двумя самостоятельными LoadImage. Неактивные ветки удаляет готовый ImpactSwitch до backend validation. Отдельные preview API не запускают геометрию/H3.
- RefMod-builder — готовые Extract/Save/Inspect/autogrow, необязательные неподключённые дополнительные фото. Своего extractor нет. UI/API1/2/8 и общий1–8, имя/тип/full-compressed/merge/presets/budget/path/preview и пример загрузки в сохранённый AIO Loader документированы.
- NativeComposite возвращает исходный PNG raster комнаты, измеряет spatial RGB SSIM и копирует исходные pixels вне actual support. Prop RGBA наносится один раз; interpolation использует premultiplied RGB, чтобы не подмешивать чёрные transparent pixels.
- Root Manager git-URL entrypoint теперь включает3DA; private Linux config/example, checksum manifest, rollback и bounded admin acceptance plan подготовлены.

Свежий API snapshot: Linux/core0.34.6/frontend1.53.6/Python3.13.14/torch2.13.0+cu130/5090. Manager V4.2.1, `/v2`, policy stable-comfyui. Найдены оба дополнительных исходника и импортированы в разные GLB, longest side по умолчанию.30м. FBX:9514 вершин/19032 треугольника,1 материал, сообщён missing image `ass_low_normal`; предоставлены3 TGA, их явная привязка и визуальная приёмка ещё нужны. Реальные физические размеры не заданы. Лицензии всех3 исходных assets unknown. Дополнительные2 объекта не приняты как готовые textured props, их live BVH/frame/gizmo/appearance checks не закрыты.

Последний перезапуск локального пакета0.3.0 остановлен **сбоем автоматической проверки разрешений из-за лимита использования**. Это не отказ по безопасности; действие не исполнялось и не обходилось. Frontend reload и проверки существующего процесса продолжены; финальная NativeComposite проверена напрямую и тестами. Запуск последних Python definitions в локальном процессе и полный studio deployment остаются отдельными проверками. Привилегированные git/network финальные действия не считать выполненными; актуальный git status проверить перед продолжением.
