# 3DA: попытка самостоятельной установки и совместимость Farm, 10.11.2026g

По прямой просьбе пользователя продолжена самостоятельная установка. Перед запросом Comfy queue была пуста (running0/pending0), Manager queue idle. Выполнен **один** штатный POST `/v2/customnode/install/git_url` с URL существующего ComfyUI-Farm. Результат: **HTTP403**, пустое тело. Restart не запрашивался; install/pip flags, network_mode, auth и другие защитные настройки не менялись. Альтернативный install route для обхода отказа не использовался. Точный raw-text формат запроса подтверждён текущим установленным `common.js`. Его UI относит403 к запрету Git URL установки; значения config.ini не читались и не угадывались.

`GET /v2/customnode/installed?mode=imported` обнаружил существующий enabled Farm: revision `e435af38c05171e3c6e141610026240c3a6b3308`. Каталог getlist(mode=local) ранее его не показывал, поэтому отсутствие в каталоге нельзя считать отсутствием checkout. Входящих SSH/терминальных подключений к студии среди доступных средств не найдено. Comfy Manager Terminal вызывает logs-terminal bottom panel: это лог, не shell. Поиск инструкции через Confluence connector завершился401; сообщения администраторам не отправлялись, credentials не менялись.

Проверка git выявила важную несовместимость: прежняя scene3d-pilot содержала более старые Farm-пульты, не включала новые optional settings/STACY_SETTINGS и RefMod outputs из установленного main. Простая замена существующего Farm на такую ветку могла убрать действующие возможности. В scene3d-pilot объединён актуальный origin/main `3afc184` с сохранением всех3DA модулей и исходного пользовательского AIO. Другие ветки не изменялись. Текстовые конфликты `.gitignore/CONTRACTS/RESEARCH/STATUS` разрешены сохранением обеих историй и последних main-строк других WS плюс текущей S3D.

Фактически проверено:

- Объединённые NGFarmPanelPhoto/Video/Face/Facepass и NGFarmShotFromTable сверены с actual studio object_info: потерянных входов0, имена/порядок выходов и типы совпадают. Динамические списки установленных моделей нормализованы как COMBO; равенство4fallback filenames вне Comfy с12реальными filenames сервера не требуется.
- Полный pytest после объединения: **486passed/3skipped/26subtests** за84.23с. Серверные GPU jobs не выполнялись. Предыдущие geometry/material/gizmo проверки10d/10f остаются отдельными доказательствами; merge не выдаётся за runtime deployment.
- Пакет3DA по-прежнему не установлен на студии; data zip не загружен, Linux geometry/Blender/env/config/persistence/native photo/video/face-pass E2E — NOT RUN. Нельзя объявлять установку успешной по HTTP-запросу, получившему403.

Для продолжения нужен один авторизованный terminal route к студии (SSH/Jupyter/console оператора). С ним можно выполнить подготовленную процедуру самостоятельно. Новый запрос разрешения пользователя на уже согласованную работу не требуется; отсутствует технический доступ. Рекомендуется установка оператором из локальной консоли с действующей политикой, а не ослабление защиты публичного HTTP endpoint.
