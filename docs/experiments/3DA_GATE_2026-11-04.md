# 3D-A — гейт «H3 ref2va + RefMod + Fun ControlNet»

Дата: 04.11.2026 · Поток: WS-3D-A (брифа `WS-NN_3D-A*.md` нет, работали по тексту задания) · Ветка: `scene3d-pilot`

## Вопрос гейта

Даёт ли связка **H3 ref2va + RefMod персонажа + location sheet + Fun ControlNet (depth локации + pose)** нужные позу, место и масштаб кадра, **не ломая идентичность и вид локации**? От ответа зависят потоки 3D-B…E.

**Ответ пока не измерен — гейт упёрся в одно административное препятствие (ядро ComfyUI на студии).** Ниже: что сделано, что измерено, что заблокировано и что нужно от администратора студии.

---

## 1. Итог в одном абзаце

Ветка 0 (без управления) на студии запускается — графы собраны и проверены по `/object_info`. Ветки 1–4 (с Fun ControlNet) **не запускаются на студии**: нода `MiniMaxH3FunControlNetApply` — это не отдельная кастом-нода, а **код ядра ComfyUI, добавленный в v0.35.0** (PR #15975); на студии стоит **0.34.6**, где её нет. В Comfy Registry — 0 совпадений, поставить её как пакет нельзя. Всё остальное сделано: карты управления отрисованы и залиты на студию (1250 файлов, проверено чтением), 50 графов веток собраны в API-формате с промптами, референсами и RefMod и лежат в репо, инвентарь моделей снят, раннер готов. **Гейт не измерен** — упёрлись в ядро студии. Вариант «второй ComfyUI ≥0.35 в своей папке» требует доступа к shell/файлам студии, которого через HTTP API нет.

### 3. Точная причина блокировки

`MiniMaxH3FunControlNetApply` — **ядро**, не кастом-нода:

- добавлена в ComfyUI **v0.35.0** (PR #15975, `comfy/ldm/minimax/controlnet.py` + три класса + ветка `minimax` в `ModelPatchLoader`);
- на v0.34.6 `/object_info/MiniMaxH3FunControlNetApply` → `{}`, в bulk-списке отсутствует;
- Comfy Registry: 0 совпадений → установить как пакет нельзя.

Единственная сторонняя реализация — `wyzborrero/ComfyUI-H3-FunControl` (Apache-2.0, `H3FunControlLoader`/`H3FunControlApply`): другие имена нод, читает из `models/controlnet/`, **нет inpaint-режима**, требует curve-form pruned-чекпоинт. Веса на студии (`minimax_h3_fun_controlnet_union_pruned_bf16.safetensors`, metadata `{"minimax_h3_fun_controlnet":"adaln_basis","format":"pt"}`) этой форме соответствуют, но отсутствие inpaint означает потерю маски персонажа — для гейта это критично (маска решает, где генерируется персонаж, а где — локация).

**Поверхность бэкпорта** (если администратор разрешит точечный патч без апгрейда): в 0.34.6 уже есть всё, кроме `comfy/ldm/minimax/controlnet.py` (404 на v0.34.6, есть в v0.35.0), трёх классов и ветки `minimax` в `ModelPatchLoader`. `set_model_patch_replace`, `comfy.patcher_extension.WrappersMP.DIFFUSION_MODEL`, `comfy.ldm.minimax.model` (DiTBlock/patchify_video/FRAME_PER_TOKEN) и `comfy.ldm.minimax.vae` (IMAGENET_MEAN) присутствуют. Единственный реальный разрыв API — `comfy.model_prefetch.pause_malloc_graph`, который **no-op**, если не активен граф comfy compiler / aimdo.

Пять веток × 5 сцен × 2 сида = **50 графов** в `workflows/3d_gate/<сцена>.<ветка>.s<сид>.api.json`:

| Ветка | Управление |
|---|---|
| 0 база | нет (18 нод) |
| 1 поза | pose, strength 1.0, start 0, end 0.6 (20 нод) |
| 2 глубина | depth, strength 1.0, start 0, end 0.6 (20 нод) |

**Референсы и RefMod** (по образцу `AIO_manual_V2.0`):
- `<Picture 1>` = `Home_Stacey_Mainroom-1.png` — лист локации (на студии проверен, 5.7 МБ, **точно та комната**, что и 3D-блок-аут);
- `<Picture 2>` = `0003.png` — эталон лица;
- RefMod `mod_1` = `ss456/split_face` (лицо), `mod_2` = `ss456/out_athleisure` (персонаж в наряде), `mod_3` = `(none)` — локация идёт листом; если понадобится RefMod локации, кандидаты на студии — `ss340/zone_Sitting-8`, `ss456/zone_sofa` (подбирать под комнату, см. §10).

**Промпты** — SFW, ref-формат для кадра, тег `[reference generation]`, своя проверка линтером (`tools/scene3d/gate_prompts.py`): шесть секций в порядке, строка камеры («filmed from one fixed position; the camera holds a completely static, locked-off shot throughout, with no camera movement, no zoom and no pan»), строка света («The lighting is preserved unchanged throughout.»), строка цвета («Colors and saturation stay unchanged from the reference image.»), слово «studio» не используется, масштаб задан предметами («the sofa seat reaches her upper thigh and the long mirror reaches above her head»), а не сантиметрами.

### Проводка `control_video`

`control_video` — вход типа IMAGE (батч), а сигнал по природе видео. Решено через `LoadImagesFromFolderKJ`: относительный путь резолвится в `os.path.join(args.base_directory, folder)`, где `base_directory` — **корень ComfyUI**, не `input/`. Поэтому значение = `input/scene3d_gate/<scene>/control/<map>`. Узел сам подгоняет батч под сетку 17n+5 (`_fit_frames`) и ресайзит в целевой размер.

*Замечание для повторения:* нода `LoadImagesFromFolderKJ` не документирует это поведение — выяснено по исходнику KJNodes `nodes/image_nodes.py` (`load_images`).

## 7. ШАГ 5 — метрики

Скрипты готовы к применению, но прогнать не на чем (ветки 1–4 не запускаются).

| Метрика | Инструмент | Источник |
|---|---|---|

## 10. Рекомендации 3D-C / 3D-D

- **3D-C (режиссёр сцен):** управление через одну карту глубины локации без персонажа работает как «план» сцены; персонаж — RefMod. Но маска обязательна: без неё Fun ControlNet рисует глубину персонажа поверх локации.
- **3D-D (движение, петли):** контрольная последовательность — 124 одинаковых кадра; для петли сигнал должен быть замкнут по кадру 124, иначе будет скачок на стыке.
- **Ограничение, специфичное для H3:** глубина и поза «съедают» текстуру (пилот: «запечённая» текстура лечится только вторым проходом без управления, снижением strength или ранним `end_percent` — не лечится).
