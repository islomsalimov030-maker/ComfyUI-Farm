# WS-07 — SFW-раунд A: основы без LoRA

Состав выбран пользователем 15.10.2026: **базовая ref2va, 10Eros beta5 (обычный hybrid, не TURBO-hybrid), PinkCherry v1.8 hybrid**. beta4 не загружать и не тестировать. Ручные воркфлоу не менять; manual_video@1 отложен.

## Матрица и готовность

- Sitting-8 / Standing-2 / Sitting-2 / Lying-4 × 3 основы × 2 фиксированных сида = **24 кадра**.
- Конфиг: [ws07_round_a.yaml](../../tools/ws07_round_a.yaml); только генератор A (`frame_h3@1 → OUT raw`), вариант fixe, без проходов лица и масок.
- **Все LoRA отключены**, включая turbo. Одинаковые референсы, промпты и сиды для каждой основы; существующий SFW-kit не изменён.
- Загрузки: [ws07_round_a_models.yaml](../../tools/ws07_round_a_models.yaml). Только три основы, используемые video VAE и Qwen-кодировщик. Два новых файла вместе **42,03 ГБ**; полный недостающий объём зависит от содержимого тома. SHA256 новых файлов взят из `lfs.sha256` HF API, не из HTTP etag; версии источников закреплены.
- Общий кодировщик ожидается уже установленным. Если его нет — стоп, автоматической замены или неизвестной загрузки нет.
- Офлайн 15.10: 24 графа собраны на настоящем SFW-kit, ошибки ссылок и линтера — 0. Тесты WS-07: **68 passed**; весь проект: **220 passed, 3 skipped**. Это не проверка загрузки весов или качества генерации.

`res_multistep / simple`, CFG 1; проход 1 — 20 шагов, проход 2 — последние 8 из сетки 20 (старт 12), shift 12. Настройки указаны явно в YAML и применяются по title к обоим сэмплерам.

В [официальном r2v-шаблоне Comfy-Org](https://github.com/Comfy-Org/workflow_templates/blob/main/templates/video_minimax_h3_r2v.json) non-turbo использует 20 шагов, `res_multistep/simple` и BasicGuider. Это ориентир для базового прохода, **не подтверждение нашего двухпроходного ref-edit**. Второй проход и shift — экспериментальный рецепт фермы. У выбранных hybrid нет подтверждённого авторского single-frame-пресета; не переносить чужой workflow другой версии как доказанный рецепт.

### Стоп-условия до генерации

1. Проверить применимость условий конкретных весов. Коммерческий допуск пока не подтверждён: автор beta5 указывает несколько донорских лицензий. [LTX 2.3](https://huggingface.co/Lightricks/LTX-2.3/blob/main/LICENSE) требует коммерческого соглашения при годовой выручке от $10M; [Krea 2](https://cdn.jsdelivr.net/gh/krea-ai/krea-2@db3984fbc6e13b34c0064990fc2d95ac64d00058/assets/hf_samples/LICENSE.pdf) — enterprise при выручке от $1M, а также содержит требования к фильтрам/распространению; [Wan2.2](https://github.com/Wan-Video/Wan2.2/blob/main/LICENSE.txt) — Apache-2.0. Применимость каждого условия к перенесённым компонентам не уточнена автором, точная донорская версия Krea не установлена. У PinkCherry указан тег Apache-2.0, но отдельный LICENSE не найден. Это не набор безусловно коммерчески разрешённых весов. Каталог кандидатов здесь не ведётся.
2. Получить SSH, проверить GPU, диск, общие модели и зависимости. Модели загружать только в `/workspace/models`; оставить минимум 20 ГБ запаса. Ничего не удалять без согласования.
3. Подтвердить совместимость hybrid с `H3ReferenceEditPrepare` реальной пробой. HTTP-проверка классов/параметров и локальная сборка графа не загружают checkpoint и не доказывают совместимость.

## Порядок на поде

Долгие операции — только в tmux, после оценки времени и стоимости (~$2/ч). Старый [многочасовой план](WS-07_plan.md) и его команды установки/загрузок не применять вместо этого раунда: они затрагивают другие серии.

1. Доставить актуальную ветку и существующий kit в `/workspace/farm/experiments/kit`. Пользовательские файлы и локальные изменения на поде не перезаписывать. Подтвердить, что `/workspace/models` доступен ComfyUI через его модельные пути.
2. После проверки лицензий выполнить инвентаризацию/загрузки в tmux (`tmux new -s ws07_round_a`, если сессии ещё нет). Кэши HF тоже направить на том:

```bash
export HF_HOME=/workspace/models/.hf_cache
export HF_XET_CACHE=/workspace/models/.hf_cache/xet
python tools/ws07_fetch.py --config tools/ws07_round_a_models.yaml --need round_a --dry
# Только если зависимости, лицензии, объём и время загрузок проверены:
python tools/ws07_fetch.py --config tools/ws07_round_a_models.yaml --need round_a
```

`--dry` ничего не скачивает, но проверяет имеющиеся файлы, включая SHA256 при его наличии. При отсутствующем локальном кодировщике, неверном размере/хеше, ошибке загрузки или нехватке места — ненулевой код, стоп. Повреждённые существующие файлы не перезаписываются.

3. План и проверка ComfyUI, без постановки генераций в очередь:

```bash
python tools/ws07_run.py plan round_a --config tools/ws07_round_a.yaml
python tools/ws07_run.py check round_a --config tools/ws07_round_a.yaml --url http://127.0.0.1:8188
```

Проверяются только выбранные руки, необходимые классы, доступные модели/комбинации параметров и каждый граф основы. Для пустой LoRA-цепи loader удалён. Старые руки, t1 VAE и дополнительные генераторы не требуются. Отсутствующая выбранная модель не заменяется другой.

4. Проба каждой основы — по одному кадру, с контролем результата и времени после каждой команды:

```bash
python tools/ws07_run.py run round_a --config tools/ws07_round_a.yaml --arm base_ref2va --limit 1 --budget-min 10
python tools/ws07_run.py run round_a --config tools/ws07_round_a.yaml --arm eros_beta5 --limit 1 --budget-min 10
python tools/ws07_run.py run round_a --config tools/ws07_round_a.yaml --arm pinkcherry_v18 --limit 1 --budget-min 10
```

Пробные задания входят в те же 24 кадра; успешные повторно не генерируются. При ошибке серия останавливается. Бюджет проверяется **между заданиями**, не является жёстким таймером текущего кадра; timeout одного ожидания — 900 с, при OOM возможен один повтор после выгрузки. За подом следить, не оставлять его ждать без плана.

5. По измерениям дать оценку оставшегося времени с учётом загрузки каждой модели и согласовать денежный/временной предел. Не использовать прежние 50 с/кадр как замер non-turbo. Для предварительного пересчёта плана можно передать измеренное `--frame-seconds` (для запаса — самое медленное время среди основ; загрузки в формуле всё ещё приблизительные).

```bash
# BUDGET_MIN установить только после проб и оценки; положительное число минут.
python tools/ws07_run.py run round_a --config tools/ws07_round_a.yaml --limit 24 --budget-min "$BUDGET_MIN"
```

Параметры руки входят в суффикс ID: изменённый рецепт не будет ошибочно пропущен как уже готовый. При изменениях промптов/референсов использовать новый каталог `WS07_OUT`; в итоговом сравнении не смешивать разные настройки. При изменении рецепта одной основы повторить согласованный набор для сопоставимости.
