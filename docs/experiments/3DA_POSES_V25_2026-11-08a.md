## Ошибки / ограничения среды
Финальный прогон постановки и все 20 H3-задач завершились без runtime-ошибок. Во время разработки были трейсбеки: несовместимые NumPy/SciPy корневой .venv; `top_grid_npz` у объекта-стены (исправлен фильтр в profiles CLI); импорт cv2 при метриках (устранена ненужная зависимость); NumPy 2 `ndarray.ptp` и пустой массив в временных preview/debug-скриптах; кодировка cp1251 при печати стрелок/эмодзи (UTF-8). Blender предупреждает HIPEW initialization failed (HIP не используется; рендеры получены). Получение официального гайда через WebFetch не сработало (402 шлюза), raw-гайд прочитан curl локально, в репо не копировался.
В одном manifest seconds включает паузу ПК (~12 часов); реальное серверное время доступно по execution_start/execution_success. В runner исправлен подсчёт по этим timestamp; результаты не пересчитывались ради времени.
DWPose/UBody используется только для диагностики: коммерческие условия весов не подтверждены (как в RESEARCH); новых библиотек/нод/весов не добавлено.
