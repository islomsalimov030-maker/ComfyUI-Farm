## Найдено у соседей (для координатора)

1. **WS-03, `farm/sheet_schema.yaml`:** заголовки с запятой не в кавычках — YAML режет их: «Свет, откуда» и «Свет, тон» оба стали «Свет», поэтому `light_dir` читает колонку тона; «Длительность, с», «Рост, см», «Высота камеры, см», «Высота, см» тоже обрезаны (работает, но не как задумано). Чинить: кавычки в YAML + переименовать две колонки «Свет» в листе. До починки направление света в промпт не попадает правильно.
2. **WS-02, `farm/bandit.py: pose_class`:** «Сидит на табуретке…, вторая рука лежит на бедре» → `lying` (ключи проверяются по классам, а не по первому глаголу). Категории бандита для Сидя-8 и Лежа-4 («лежит, опираясь…» — верно) путаются. В сборщике свой классификатор по первому глаголу (`builder.pose_class`), бандит не трогал.
3. **Справочники в листе пустые:** `desc_en` персонажа/нарядов/плит, «Якоря», «Слоты», «Свет» — нет. Сборщик работает и так (место и наряд описывает LLM/ссылка на картинку), но якорь масштаба из карточки появится только после разметки плит (`tools/plate_marker.html`).

## План прогона LLM на поде (≈ 30 мин, ≈ $1; можно в одной сессии с WS-07/WS-10)

ComfyUI не нужен; GPU нужен только Ollama (~7 ГБ VRAM на 8b q4). Под поднимает пользователь (LAUNCH, туннель с `-L 11434 -L 8888`).

| # | Шаг | Команда (терминал JupyterLab `localhost:8888` или Claude Code на поде) | Время |
|---|---|---|---|
| 1 | код | `cd /workspace/farm/repo && git pull && pip install -q 'jinja2>=3.1'` | 1 мин |
| 2 | модель | `echo $OLLAMA_MODELS` (должно быть под `/workspace/models`); `ollama list \| grep qwen3-vl:8b-instruct \|\| ollama pull qwen3-vl:8b-instruct` (6.1 ГБ) | 0–5 мин |
| 3 | офлайн-проверка | `python -m pytest -q tests/test_ws04_prompts.py` | 10 с |
| 4 | прогон | `python tools/ws04_llm_eval.py --model qwen3-vl:8b-instruct --reps 3` — 20 строк × 2 стадии × 3 = 120 запросов | ~10–15 мин |
| 5 | если < 95 % | `--format json` (без схемы) и сравнить; затем (по желанию) `qwen3.6:27b` одним повтором `--reps 1` | 10 мин |
| 6 | отчёт | `cp $FARM_HOME/logs/ws04_llm_eval_*.md docs/audit/WS-04_llm_eval.md`, глазами 3–5 промптов, коммит | 5 мин |
| 7 | уборка | модель выгружается сама (`keep_alive: 0`); лишние модели — `ollama rm`, записать в STATUS | 1 мин |

**Готово, когда:** `first_try_json_ok_pct ≥ 95` и `lint_clean_final = n` (скрипт вернёт код 0). Если линтер ловит ошибки после правок — смотреть `error_codes` в отчёте: правка системного промпта `farm/prompts/system/sfw_v1_*.md`, не шаблона.

Риски: тег `qwen3-vl:8b-instruct` на поде может отсутствовать (тогда `pull`), структурированный вывод требует Ollama ≥ 0.5 (`ollama -v`).
