# farm_auto — фото и видео по таблице сцен

**Что делает.** Берёт строку таблицы сцен (xlsx) → блок ФОТО делает кадр 3 Мп с проходом лица → блок ВИДЕО делает
зацикленное видео FullHD 24 fps с проходом лица. Промпты пишет LLM фермы (Ollama) по шаблонам MiniMax H3.
Работает на поде фермы (нужны пакет ComfyUI-Farm и Ollama).

## Быстрый старт
1. **ТАБЛИЦА** → поле `table`: путь к xlsx на поде (пусто — таблица из настроек фермы). В работу идут только строки
   с галочкой «В работу».
2. `row` — номер строки среди отмеченных (1 — первая), `shot_id` — конкретный ID (важнее номера).
   Прогнать N строк подряд: `row = 1`, control `increment`, рядом с Run поставить N и нажать Run.
3. **Модели** — включатели `use_ref2v / use_10Eros / use_PinkCherry / use_Singularity` (последний — внизу пульта) в ПУЛЬТЕ ФОТО и ПУЛЬТЕ ВИДЕО. Каждая
   включённая даёт свою версию; считаются **по очереди** (первая — в этом запуске, остальные сами встают в
   очередь ComfyUI через несколько секунд после старта первого), поэтому памяти хватает. Блоки целиком включаются/выключаются нодой ВКЛ/ВЫКЛ вверху.
4. **ПЕРЕКЛЮЧАТЕЛЬ** посередине:
   - «из блока фото» — фото и видео за один запуск (видео берёт первый готовый кадр: ref2v → 10Eros → PinkCherry);
   - «из папки готовых кадров» — блок фото выключить, видео делается по уже принятым кадрам из папки/ZIP
     (`farm_zip/photo` по умолчанию; имя файла начинается с ID шота).
5. Run. Итоги — в группах ИТОГ и в **ZIP фото / ZIP видео**: в ноде появится ссылка на скачивание архива.

## Что берётся из таблицы
- Фото: Персонаж (персонаж в наряде → моды лица и тела), Зона или «Картинка локации», Класс позы, План,
  Лицо в кадре, Ракурс и кадр, Поза, Эмоция, Объекты.
- Видео: Действие, Что двигается, Амплитуда, Возврат в базу, Эмоция, Петля, Длительность, Видео-реф движения.
- Колонки другого блока не влияют.

## Локации
- По умолчанию — лист ракурсов зоны из справочника фермы (`refs/zones/<зона>/sheet.png`).
- «Картинка локации» в строке — эта картинка как есть.
- **ЛОКАЦИЯ 1–4** (необязательно): загрузите картинку с именем файла = ID зоны (`loft_bath.png`) — она пойдёт
  вместо табличной для всех строк этой зоны. Не нужны — выключите (mute).
- Совет: где ракурс понятен — одна картинка, а не лист: лист иногда «утекает» в кадр коллажем.

## Пульты
- **ПУЛЬТ ФОТО** — сиды, шаги по моделям, shift, размер входной картинки, доработка, сила прохода лица.
- **PANEL** (видео) — длительность и петля приходят из таблицы; режим, сид, проход лица (auto), free_vram.
- **ПУЛЬТ ВИДЕО** — тонкая настройка: шаги по моделям, фиксация цвета, шов петли, стабилизатор дрожи,
  параметры прохода лица (flow-lock, руки, кроп).
- Наведите курсор на поле — появится подсказка.

## Модели
- ref2v — официальная H3 ref2va + turbo-LoRA, 8 шагов, быстрее всех.
- 10Eros, PinkCherry — дообученные H3 без turbo, 20 шагов (≈2,5× дольше). У 10Eros лицензии доноров
  (LTX 2.3, Krea 2) — для прода проверить.
- Singularity ref2va v1.3 — дообученная H3 без turbo (Apache-2.0 в карточке HF), 20 шагов.

## Если что-то не так
- «нет строки «В работу»» — поставьте галочку в таблице. «не прошёл линтер» — в промпте осталась кириллица или
  нарушено правило: поправьте текст строки.
- Видео дрожит — ПУЛЬТ ВИДЕО: temporal_strength 1, face_lock 1. Цвет уплывает — color_lock 0.5–1.
- Не хватает памяти — включите одну модель; PANEL → free_vram on.
