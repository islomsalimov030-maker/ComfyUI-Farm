# collage@1 — коллаж из 4+ фото

**Что делает.** Собирает коллаж-сетку из нескольких фотографий. Восемь узлов загрузки сверху слева, две ветки сборки, переключатель режима, превью и сохранение.

**Как запустить**
1. Откройте `workflows/collage@1.ui.json` в UI студии (ComfyUI → Workflows → Load, либо перетащите файл в браузер).
2. Перетащите фото в узлы **«IN 1 · фото» … «IN 4 · фото»** (виджет «choose file to upload»).
3. Выберите режим в узле **«KNOB режим»**: `false` — «рамки», `true` — «плотная».
4. **Queue**. Итог — превью в узле «ПРЕВЬЮ» и файл `output/collage/collage_0000N_.png`.

**Две ветки сборки**
- **«СЕТКА · рамки»** (`false`) — каждое фото растягивается в ячейку `cell_w × cell_h`, между ячейками чёрный отступ `padding`. Быстро и ровно, но пропорции фото меняются (квадратное фото в прямоугольной ячейке растянется).
- **«СЕТКА · плотная»** (`true`) — фото вписывается в ячейку **с сохранением пропорций**, пустоты добиваются цветом `pad_color`, отступов между ячейками нет. Разного размера фото не искажаются.

**Ручки (все в узлах «KNOB …»)**
- `columns` — сколько фото в ряду. Для 4 фото — `2`, для 5 — `3`, для 6 — `3`, для 8 — `4`, для 9 — `3`.
- `cell_w` / `cell_h` — размер ячейки в пикселях. Итог: `columns × cell_w` (+ отступы) в ширину.
- `padding` — зазор между ячейками, только для «рамок» (0–50).
- `pad_color` — цвет добора «R, G, B» (например `20, 20, 20`), только для «плотной».
- `режим` — `false` = рамки, `true` = плотная.

**Больше 4 фото.** Скопируйте узел «IN» (Ctrl+C → Ctrl+V), загрузите в копию фото и подключите к свободному входу «БАТЧ» (`image_5`, `image_6`, …). Неподключённые входы нода «БАТЧ» пропускает — пустые слоты не ломают прогон. Лимит — 8 заготовленных слотов, `inputcount` в «БАТЧ» можно поднять до 1000.

> ⚠ Не оставляйте узел «IN» с пустым файлом, пока он **подключён** к «БАТЧ»: `LoadImage` с пустым именем роняет прогон (`Is a directory: input`).
