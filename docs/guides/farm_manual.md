# farm_manual — фото и видео вручную

**Что делает.** Те же движки, что у фермы, но без таблицы и LLM: промпты и картинки задаёте вы.
Три независимых блока: ФОТО, ВИДЕО, ПРОХОД ЛИЦА ГОТОВОГО ВИДЕО. Работает на поде и на сервере студии.

## ФОТО
1. **ФОТО · локация** — картинка локации или лист ракурсов (`<Picture 1>`). Лучше одна картинка нужного ракурса.
2. **ФОТО · моды** — mod_1 = лицо персонажа (`farm/samantha_face`), mod_2 = персонаж в наряде
   (`farm/samantha_athleisure_body`). **ФОТО · мод лица** — тот же мод лица для прохода лица.
3. **ФОТО · промпт кадра** — промпт H3 (структура: subject_definitions, summary, retention_analysis,
   detailed_description). Обязательно: «one single photograph, never several panels», статичная камера,
   свет и цвет без изменений. Слово «studio» не использовать.
4. **ФОТО · промпт прохода лица** — короткий портретный промпт.
5. **Маска (необязательно)** — дорисовать только часть готового кадра: загрузите кадр в «МАСКА · исходный кадр»,
   правый клик → Open in MaskEditor → закрасьте область → «МАСКА ВКЛ» = true. Вне маски кадр не меняется.
6. Модели — включатели в ПУЛЬТЕ ФОТО (по очереди, отдельными запусками) → Run. Итог — «ИТОГ фото · <модель>».

## ВИДЕО
1. **ВИДЕО · ключевой кадр** — первый (и последний для петли) кадр.
2. **ВИДЕО · эталон лица** — крупное лицо персонажа (`<Picture 2>`).
3. **ВИДЕО · промпт видео** — промпт H3 по гайду: таймкоды действий, статичная камера, возврат в исходную позу.
4. **ВИДЕО · видео-референс** (необязательно) — видео движения (`<Video 1>`), упомяните его в промпте.
5. **ВИДЕО · конечный кадр** — только если петля выключена (переход в другую позу).
6. **PANEL** — длительность, петля, сид, free_vram. Проход лица здесь выключен.
7. Модели — включатели в ПУЛЬТЕ ВИДЕО → Run. Итог — «ИТОГ видео FullHD · <модель>».

## ПРОХОД ЛИЦА ГОТОВОГО ВИДЕО (отдельно)
Для сервера студии, где генерация и проход лица вместе не помещаются в память.
1. Включите группу «ПРОХОД ЛИЦА…», остальные блоки выключите.
2. «ВИДЕО для face pass» — загрузите видео. Промпт прохода лица — короткий портретный.
3. Run. Итог — «ИТОГ face pass готового видео».

## Пульты
- **ПУЛЬТ ФОТО**, **ПУЛЬТ ВИДЕО**, **ПУЛЬТ ПРОХОДА ЛИЦА** — все ручки блока в одной ноде, у каждого поля подсказка.
- Модели: ref2v (turbo, 8 шагов) — быстро; 10Eros, PinkCherry и Singularity — 20 шагов (шаги и turbo пульт ставит сам).
  Один движок на блок, модели считаются по очереди — без OOM.
- **«steps_override» (шаги сэмплера)** — 0 = как положено модели, число больше 0 = перекрыть вручную.
  Нужно, когда модель без turbo (20 шагов = в 2.5 раза дольше turbo-модели) и надо ускориться:
  поставьте 8 — генерация пойдёт примерно втрое быстрее по сэмплированию, но кадр/видео
  выйдут недогарёнными (для дообученных без turbo моделей качество важнее скорости —
  в этом случае лучше переключиться на `use_ref2v`).

### Почему генерация медленная (29.10, WS-14)
- **Пустые 20 шагов вместо 8** — самый частый случай: в пульте включена дообученная модель без turbo
  (Singularity / 10Eros / PinkCherry), а turbo-LoRA в воркфлоу обойдён (узел «ARM lora · turbo» в режиме bypass).
  Проверьте ПУЛЬТ ВИДЕО: для быстрого прогона нужен `use_ref2v` (turbo 1.0, 8 шагов) — на поде такой прогон
  занимает ~12–13 минут, а 20 шагов без turbo заметно дольше.
- **`--cache-none` на поде** — обязателен при лимите контейнера 94 ГБ (иначе OOM), но он не кэширует выходы узлов,
  поэтому повторный запуск пересчитывает всё заново. На скорость одного прогона почти не влияет.
- **RTX VSR ULTRA** (апскейл 1920×1096) и `VHS_KeepIntermediate` — заметно добавляют времени к постобработке.
