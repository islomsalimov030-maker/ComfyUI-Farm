# Тестовая SFW-таблица Стейси для 3D (поток 3D-A, пункт 3)

Пять строк листа «Сцены» по схеме `farm/sheet_schema.yaml` v2.1. Схема не менялась. В конце добавлена одна колонка «3D (JSON)»: валидатор и нода её не читают, потому что лишние колонки пропускаются.

## Файлы и формат
| Файл | Для чего |
|---|---|
| `stacy_sfw_test.xlsx` | **Его читает нода.** `NGFarmShotFromTable` → `farm/shot_node.py:load_row` → `Sheets(XlsxBackend(path))`. Нода понимает только xlsx: CSV и JSON напрямую она не читает. В книге есть листы «Сцены», «Персонажи», «Зоны», «Наряды» (пустой), «Объекты» и «Профили». Путь к файлу вписывается в поле `table` ноды (или в `farm.yaml → sheets.xlsx`). |
| `stacy_sfw_test.csv` | Тот же лист «Сцены» в формате UTF-8 с BOM: удобно вставить в Google Sheet или посмотреть глазами. Справочников в нём нет. |
| `stacy_sfw_test.json` | `rows` — строки, ключи совпадают с заголовками, «3D (JSON)» хранится объектом. `render_specs` — готовые спеки для `render_plate_scene.py` по локациям, в формате `scenes_mainroom*.json` (`photo, size, room, light, scenes`). |

Как проверено: офлайн, `Sheets.check(check_files=False)`, то есть так же, как это делает нода. Результат: 5/5 строк в работу, ошибок 0, предупреждений 0, замечаний к справочникам нет. Файлы на диске (`refs/`, лист ракурсов) не проверялись.

## Что нужно добавить, чтобы строки отрисовались точно
- **Позы в `tools/scene3d/poses.py`:**
  - `stand_cup` — правая кисть с кружкой у груди, левая рука висит (`HANG L`), голова к камере;
  - `crouch_shoelace` — `crouch`, обе кисти у правого кроссовка, голова опущена;
  - `lie_read` — `lie_back`, обе руки держат книгу над грудью, лицо открыто;
  - `stand_back_look` — `stand_back` (`yaw_add` 180), голова и плечи повёрнуты через левое плечо к камере, примерно на 60–80° вместо нынешних 20°.
- **Предметы:** `builtin:cup` и `builtin:book` уже есть в рабочей копии `render_plate_scene.py` (правки не закоммичены). Если в основной ветке их нет, их нужно добавить.
- **Новые модели и библиотеки не нужны.**
