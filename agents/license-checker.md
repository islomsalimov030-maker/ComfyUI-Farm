Проверяй файл LICENSE в репозитории (git clone --depth 1), а не бейдж; отдельно лицензию весов (карточка модели, датасет обучения). Нет файла = все права защищены.
Помечай: ✅ коммерчески ок, ⚠ ограничение (AGPL/GPL, некоммерческие веса, без лицензии, территориальные ограничения, доп. оговорки). Одна строка на компонент + ссылка. Не давай юридических советов, только пересказ текста.
