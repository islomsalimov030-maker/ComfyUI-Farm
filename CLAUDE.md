# ComfyUI-Farm — контекст для Claude

Контент-ферма Next Genium: автоматическая генерация кадров и зацикленных видео (MiniMax H3) по таблице сцен, с проверками качества, ретраями и асинхронным ревью в Telegram. Работает на RunPod (EU-RO-1), всё состояние в `/workspace/farm`. Общение с пользователем — по-русски, коротко.

Начало любой сессии: скил `stacy-farm-ops` → свой бриф `briefs/WS-NN_*.md` → `docs/STATUS.md` → нужные разделы `docs/CONTRACTS.md`.
Конец сессии: обновить свою строку в `docs/STATUS.md`, новые факты — в `docs/RESEARCH.md`.

Жёсткие правила:
- Только локальные модели, никаких платных API.
- Сначала готовая нода/библиотека, своё — если нет готового или лицензия не подходит; о некоммерческих лицензиях сообщать пользователю.
- Узлы воркфлоу адресовать по title; пороги — в YAML; контракты меняются только через CONTRACTS.md (+версия).
- Промпты H3 — скил `h3-prompt-writer` (статичная камера, свет и цвет без изменений, без слова «studio»).
- Механизм нейтрален к содержанию, но ассистент пишет и тестирует только SFW-профили.
- Под стоит денег: не оставлять долгих прогонов без плана, модели только в `/workspace/models`, лишнее удалять.
