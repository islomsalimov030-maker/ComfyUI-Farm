# Протокол сессии фермы

## Старт (до любой работы)
1. Определи поток: пользователь пишет `WS-NN` или прикладывает бриф `briefs/WS-NN_*.md`. Нет брифа — спроси номер потока одним вопросом.
2. Прочитай только нужное: бриф потока → `docs/STATUS.md` (строка своего потока + «Решения») → `docs/CONTRACTS.md` (разделы, указанные в брифе). `STACY_CONTEXT.md` и `STACY_FARM_PLAN.md` — по ссылкам из брифа, не целиком.
3. Сверь «Вход» брифа с реальностью (файлы есть? под нужен?). Если под нужен, а его нет — делай офлайн-часть и скажи, что нужно от пользователя.

## Где живёт состояние
- Код и документы — git-репозиторий `ComfyUI-Farm` (GitHub islomsalimov030-maker). Пока GitHub не подключён к claude.ai — папка на ПК `C:\stacy-lora\farm-kit\` через мост устройства; отдавать файлы через SendUserFile.
- На поде: `/workspace/farm/` (repo, db, results, refs), модели `/workspace/models/...`, логи `/workspace/logs/`. Всё вне `/workspace` исчезает при Terminate.
- Решения, которые меняют контракты, — только через `docs/CONTRACTS.md` (версия +1) и строку в «Решения» STATUS.md.

## Работа с подом (RunPod EU-RO-1, гайд работодателя)
- Под поднимает пользователь: Template `linear_ivory_antlion`, Secure Cloud, том `physical_harlequin_ferret`; SSH с `-L 8188 -L 8675 -L 11434 -L 8888`; затем `/workspace/bootstrap.sh` до `УСПЕХ`. HTTP-порты не открывать, Community Cloud не брать.
- Доступ ассистента: Chrome пользователя → `localhost:8888` (JupyterLab, терминал = shell на поде) и `localhost:8188/system_stats` (лёгкая страница для `fetch` к `/prompt`, `/history/<id>`, `/view`, `/upload/image`, `/queue`, `/free`). Тяжёлый редактор не открывать без нужды. Либо Claude Code прямо на поде (конфиг `/workspace/.claude`, скилы в `/workspace/.claude/skills`).
- JS-вызовы в Chrome ≤45 с: длинное — фоновой async-функцией + опрос. Не хранить и не eval-ить код из localStorage.
- VRAM: ComfyUI `POST /free {"unload_models":true,"free_memory":true}`; Ollama `keep_alive:0` или `ollama stop`. Группировать задачи по модели.
- Деньги: ~$2/ч. Не оставлять длинных прогонов без присмотра; в конце дня пользователь делает Stop → **Terminate**. Перед этим всё нужное — в `/workspace` или скачано.
- Новые модели — только в `/workspace/models`; после тестов неиспользуемое удалить и записать в STATUS.

## Правила работы
- Делай сам максимум, не спрашивай о мелочах; спрашивай только про необратимое или реально неоднозначное.
- Экономь токены: большие JSON и логи читай скриптом (grep/python), не целиком; не пересказывай файлы.
- Сначала готовая нода/библиотека (скил `comfyui-workflow-json` §4), всегда проверяй лицензию и сообщай о некоммерческих.
- Промпты H3 — по скилу `h3-prompt-writer`.
- SFW-граница: механизм нейтральный, но NSFW-промпты, таблицы, критерии и тесты не пишем и не запускаем.
- Если контекст стал большим (много крупных файлов/логов) или поток сменился — предложи пользователю новый чат и выдай блок передачи.

## Финиш сессии (обязательно)
1. Обнови свою строку в `docs/STATUS.md`: статус, что сделано, артефакты (пути/ссылки), блокеры, следующий шаг.
2. Новые факты о моделях/нодах/лицензиях — в `docs/RESEARCH.md` (одна строка + источник).
3. Выдай пользователю короткий отчёт: результат, проблемы, ограничения, что нужно от него. Без пересказа шагов.
4. Если поток не закончен — блок «ПЕРЕДАЧА» (≤15 строк): где остановились, команды для продолжения, открытые вопросы.
