# Бот ревью фермы (WS-08)

Telegram-бот, через который вы и коллеги принимаете кадры и видео, не останавливая конвейер.
aiogram 3 (**MIT**), long polling — входящих портов нет. Бот — отдельный процесс рядом с ComfyUI:
читает БД фермы (`$FARM_HOME/db/farm.sqlite`), пишет только в `reviews`, пультом управляет через
`/farm/status` и `/farm/control` на `127.0.0.1:8188` (CONTRACTS §9).

## Что умеет
| Кнопка | Что происходит |
|---|---|
| ✅ Принять | `reviews(verdict=accept)` → оркестратор: кадр → видео, видео → `approved`, выгрузка |
| 🔁 Переделать | `reviews(verdict=redo)` → стадия заново (попытки помечаются `superseded`) |
| ✍️ Переделать с комментарием | следующее сообщение = комментарий → `redo_comment`, текст уходит сборщику промптов |
| ▶️ Запустить пакет | меню профилей или фильтр текстом: `профиль=a,b приоритет=1 id=S-01,S-02` (приоритет как в таблице: 1 — срочные, `приоритет<=2` — срочные и обычные); `/batch <фильтр>` |
| 📊 Статус очереди | состояние воркера + шоты по стадиям + сколько вердиктов ждёт оркестратора |
| ⏸ Пауза | новые задания не отправляются, начатые в ComfyUI доделываются; «▶️ Продолжить» — как было |
| 📥 Ожидают | все открытые кандидаты и «нужен человек» прямо сейчас (`/pending`) |

Уведомления: «нужен человек» — сразу (не чаще раза в минуту), обычные кандидаты — дайджестом раз в 15 мин
(до 10 карточек, остальное в следующем). Очередь уведомлений лежит в `$FARM_HOME/state/bot_<name>.sqlite`
и переживает рестарт: карточка считается отправленной только после ответа Telegram, повтор без дублей.
После вердикта у всех копий карточки исчезают кнопки и появляется строка «✅ Принято — кто».

Превью: кадр — фото (больше 9,5 МБ → JPEG); видео ≤ 20 МБ — mp4-«гифка» (петля крутится сама), больше —
пережатие ffmpeg до 720/480/360 px, в крайнем случае файлом или текстом. Всё — в `bot/config.example.yaml`.

## 1. Создать бота у @BotFather (2 минуты)
1. В Telegram открыть **@BotFather** → `/newbot` → имя (например, `NG Farm Review`) → username на `_bot`.
2. Скопировать токен вида `123456:ABC…`. **Никуда не коммитить и не пересылать в чаты.**
3. Для работы в группе: `/setprivacy` → Disable (иначе бот не видит кнопки меню и текст в группе;
   в личке это не нужно). Добавить бота в группу.
4. `/setjoingroups` → Disable после того, как бот добавлен, — чтобы его не добавили в чужие чаты.

## 2. Секреты на поде (только в `/workspace/farm/secrets/`, chmod 600)
```bash
mkdir -p /workspace/farm/secrets && chmod 700 /workspace/farm/secrets
cd /workspace/farm/secrets
printf 'FARM_BOT_TOKEN=123456:ABC...\n' > .env
cat > bot_access.yaml <<'EOF'
reviewers: [111111111, 222222222]   # кто жмёт ✅ 🔁 ✍️ (вы и коллеги)
operators: [111111111]              # кто запускает пакеты и ставит паузу (по умолчанию = reviewers)
notify_chats: [111111111]           # куда слать карточки: личка или группа (-100…)
EOF
chmod 600 .env bot_access.yaml
```
Свой id: запустить бота (шаг 3) и написать ему `/whoami` — он ответит id даже без доступа.
Конфиг по умолчанию — `bot/config.example.yaml`; своё (другие профили, частота дайджеста) —
`secrets/bot_main.yaml` с нужными ключами, бот подхватит его сам.

## 3. Запуск в tmux на поде
```bash
REPO=$(find / -maxdepth 6 -type d -ipath '*custom_nodes/comfyui-farm' 2>/dev/null | head -1)  # тот же клон, что у нод
cd "$REPO"
pip install -r bot/requirements.txt
python -m bot --check                                    # БД, доступ, токен, связь с пультом
tmux new -d -s farmbot "cd $REPO && python -m bot 2>&1 | tee -a /workspace/farm/logs/bot_main.log"
tmux attach -t farmbot        # посмотреть; выйти не останавливая — Ctrl+B, затем D
tmux kill-session -t farmbot  # остановить
```
ComfyUI с пакетом фермы должен быть запущен (иначе «Статус» покажет данные БД, а ▶️/⏸ — «нет связи»).
После Terminate пода tmux пропадает — запустить заново той же командой (состояние бота на томе).

## 4. Второй бот для другой команды — без правки кода
Новый токен у @BotFather, затем `secrets/bot_team_b.yaml`:
```yaml
name: team_b                      # своё состояние: state/bot_team_b.sqlite
token_env: FARM_BOT_TOKEN_TEAM_B  # строка в secrets/.env
access_file: secrets/bot_access_team_b.yaml
profiles: [team_b_profile]        # видит и запускает только свои профили
```
`tmux new -d -s farmbot_b "cd $REPO && python -m bot --config /workspace/farm/secrets/bot_team_b.yaml"`.
⚠ Пульт воркера общий: ▶️ второго бота переключает активные профили всей фермы. Для одновременной
работы двух команд запускайте пакет с профилями обеих или договоритесь об очереди.

## Запуск на своём ПК
Бот должен видеть файл БД и пульт. С ПК это возможно только при SSH-туннеле `-L 8188` и копии БД —
поэтому основной режим — на поде. Код кроссплатформенный (Windows тоже).
