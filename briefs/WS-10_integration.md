# WS-10 · Интеграция и первый сквозной прогон

**Скилы:** все проектные. **Под:** да, 2–3 сессии.
**Прочитать:** STATUS целиком, CONTRACTS, README каждого модуля.

## Цель
10 SFW-шотов Стейси из таблицы проходят всю цепочку на поде без участия человека, кроме ревью в боте.

## Шаги
1. Установка на под: `ComfyUI-Farm` через Manager по git-URL, зависимости, модели по `profiles/sfw_base.yaml`, Ollama-модели, секреты, бот в tmux. Скрипт `install/pod_setup.sh` (идемпотентный, всё в `/workspace`).
2. Прогон 10 шотов: метрики (доля принятых без правки, GPU-минуты на принятый клип, ретраи по кодам отказа).
3. Калибровка порогов по решениям в боте (логистическая регрессия по P(Yes)/метрикам), обновление `thresholds_*.yaml`.
4. Перезапуск пода (Terminate → новый под) и проверка, что очередь продолжается.
5. Отчёт: узкие места, что отключить (слабые руки бандита), стоимость часа фермы.

**Готово, когда:** 10/10 шотов дошли до approved или needs_human с понятной причиной, перезапуск не теряет состояние.
