# WS-09 · Ручная версия воркфлоу (маска без шва)

**Скилы:** stacy-farm-ops, comfyui-workflow-json. **Под:** короткая проверка.
**Прочитать:** STACY_FARM_PLAN §4 «Ручная маска»; итоги WS-01.

## Цель
Воркфлоу для людей, которые доделывают отказы автоматики: те же движки, но с ручными входами, маской из MaskEditor и вклейкой без шва, смены цвета и сдвига фона.

## Шаги
1. Взять движки WS-01, пульт с ручками из `params.yaml`, выбор «руки» (модель+LoRA) и RefMod вручную.
2. Маска: кроп по маске → перерисовка кропа → ColorMatch к исходному кропу → вклейка **только по маске с растушёвкой поверх исходных пикселей** (Inpaint-CropAndStitch, GPL-3). Фон вне маски не проходит через VAE.
3. Проверка: разница пикселей вне маски = 0; шов не виден на 5 тестовых кадрах.
4. Кнопка «загрузить шот из фермы по ID» (параметры последней попытки из БД) — если WS-02 готов, иначе позже.

## Результат
`workflows/manual_frame@1.ui.json`, `manual_video@1.ui.json` в формате пользователя (README + Шпаргалка).
