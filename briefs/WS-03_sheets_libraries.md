# WS-03 · Таблица сцен и библиотеки

**Скилы:** stacy-farm-ops, google-workspace. **Под:** нет.
**Прочитать:** CONTRACTS §3, §10; STACY_FARM_PLAN §3; бриф пользователя раздел «В».

## Цель
Таблица, которую коллеги заполняют по-русски без инструкций в голове, и код, который её читает и проверяет.

## Шаги
1. Google Sheet «Ферма — сцены» (в аккаунте пользователя): листы `Сцены`, `Персонажи`, `Локации`, `Наряды`, `Объекты`, `Профили`, `Как заполнять`. Выпадающие списки по ID справочников, проверка длительности 5–10, петля да/нет, защищённые колонки оркестратора, условное форматирование статусов.
2. Карточка плиты: колонки + YAML-формат (CONTRACTS §10); инструкция, как разметить якоря (bbox) — простой способ без кода (например, координаты из любого редактора) или маленький HTML-инструмент для клика по плите.
3. `farm/sheets.py`: чтение через сервисный аккаунт (gspread или Google API), валидатор строк (понятные ошибки по-русски в колонку `Статус`), запись статусов. `farm/library.py`: разрешение ID → файлы/RefMod в `refs/`.
4. Инструкция «как создать сервисный аккаунт бесплатно и дать доступ к таблице» (по шагам, со скриншотными подсказками текстом).
5. Однократный перенос из Confluence «Таблицы SFW для Стейси»: только SFW-позы (30 строк, без Лежа-3), через выгрузку, которую даст пользователь, или через Chrome.

## Результат
Ссылка на Sheet, `sheets.py`, `library.py`, тесты валидатора на 10 строках (5 с ошибками), инструкция SA.
**Готово, когда:** валидатор ловит все типовые ошибки, а 30 SFW-строк Стейси проходят.
**Не входит:** NSFW-таблицы (их переносит команда).
