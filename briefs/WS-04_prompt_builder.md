# WS-04 · Промпты: LLM-сборщик и линтер

**Скилы:** stacy-farm-ops, h3-prompt-writer, vendor `minimax-h3-video`. **Под:** для прогона LLM (полсессии), остальное офлайн.
**Прочитать:** CONTRACTS §5, §7; ПРОМПТ-ГАЙД и образец промпта внутри `Stacy_H3_compact (5).json` (MarkdownNote «ПРОМПТ-ГАЙД», «Образец промпта Sitting-8»); STACY_CONTEXT §4 (fix_e) и §7.

## Цель
Из строки таблицы (поза и действие по-русски) автоматически получать промпт кадра и промпт видео-петли, которые проходят линтер и соответствуют гайду H3 и правилам пользователя.

## Шаги
1. Шаблоны Jinja2: `frame_ref_v1`, `video_loop_ref_v1`, `video_transition_ref_v1` (loop off + end_frame), вариант с `<Video 1>`. Обязательные строки — в шаблоне, не в LLM.
2. JSON-схема полей, которые пишет LLM (позы/фазы/неподвижные части/выражение/звук), системный промпт для **SFW** (рус→англ, механика движения, стороны тела, запреты). Профиль может подменить системный промпт — механизм, не содержание.
3. `lint.py`: все правила из скила `h3-prompt-writer` §4–§7 + проверка, что метки `<Picture N>` совпадают с подключёнными входами `params.yaml`.
4. `llm.py`: клиент Ollama (`/api/chat` с `format: json`, ретрай при невалидном JSON ≤2, `keep_alive:0` после пакета).
5. Набор из 20 SFW-строк (позы Стейси) → golden-тесты: сборка + линтер без LLM (фикстуры JSON-полей) и с LLM (на поде).
6. Автоматическая строка масштаба из карточки плиты (якорь «X reaches her Y»).

## Результат
`farm/prompts/*`, тесты, отчёт «20 строк → 20 промптов, 0 ошибок линтера», 3 примера в README.
**Готово, когда:** golden-тесты зелёные; на поде LLM выдаёт валидный JSON ≥95 % с первой попытки.
**Не входит:** NSFW-системные промпты и примеры.
