# WS-06 · Проверки видео и постобработка петли

**Скилы:** stacy-farm-ops, vendor `video-upscale`. **Под:** нет (готовые видео с ПК); GPU — только для RAFT/VLM, можно CPU на 480p.
**Прочитать:** CONTRACTS §8; отчёт «Конвейер…» разделы «Луп first=last…» и «Видео проверяет дешёвое CV…»; бриф пользователя G5 (не те движения, слоу-мо, неестественные начало/конец).

## Вход
`C:\stacy-lora\frames\sfw_videos_v2\videos\` (готовые петли) + соответствующие ключевые кадры; при необходимости `h3lab\`, `review\`. Ручная разметка пользователя: 10–15 клипов «хорошо/плохо + причина» (попросить, когда будет инструмент).

## Шаги
1. `post/loop.py`: поиск ближайшего к кадру 0 среди последних ~12 кадров и обрезка дубля; кроссфейд 6–10 кадров; мост RIFE (Apache/MIT — проверить веса) как опция.
2. Проверки: `seam` (LPIPS/1−SSIM шва vs медиана соседних, порог 1.5×), `seam_velocity` (направление потока до/после шва), `freeze` (серии малоподвижных кадров), `slowmo` (средняя скорость движущихся пикселей vs ожидаемая по длительности фаз промпта), `camera_move` (поток по фону вне маски человека + RANSAC), `color_drift`/`light_drift` (LAB по фону и коже против ключевого кадра), `flicker`, `cut` (PySceneDetect), `identity_dip` (минимум и провалы сходства лица по кадрам, yaw>45° пропуск).
3. Маршрутизация: жёсткий провал → новый seed; провал только шва → постобработка; пограничный → человеку.
4. Мини-инструмент разметки (HTML-артефакт или лист в Sheets), чтобы пользователь отметил 10–15 клипов; калибровка порогов.

## Результат
`farm/qa/video/*`, `farm/post/*`, отчёт по готовым видео (что поймано, что пропущено).
**Готово, когда:** на размеченных клипах проверки совпадают с человеком ≥80 %, а постобработка шва убирает видимый рывок без перегенерации на ≥ половине клипов с плохим швом.
